# SQLab Pro

> 让每一条 SQL，上线前都被认真对待 —— 开源 SQL 测试工作台：查询执行 / 性能分析 / 规范校验，一站完成。

## 这是什么

SQLab Pro 是面向研发团队的 SQL 测试工作台项目，目标是让每条 SQL 在上线之前完成一次「体检」：写完就测、慢了就看、不合规范就拦。

本仓库当前包含项目的三大核心交付物（纯前端原型阶段，无需后端即可体验）：

| 文件 | 说明 |
| --- | --- |
| `index.html` | 高保真交互原型（单文件，浏览器直接打开） |
| `PRD.md` | 产品需求文档（PRD）初稿 |
| `PPT脚本.md` | 10 页开源路演 PPT 内容脚本 |

## 原型功能

- **SQL 查询**：语法高亮编辑器、`Ctrl+Enter` 快捷执行、50 条 Mock 数据分页表格、CSV 导出
- **性能分析**：EXPLAIN 计划节点流可视化（全表扫描自动标红）+ 慢查询 P95 耗时 / 执行次数趋势图
- **规范检查**：Error / Warning / Info 三级结果，含规则 ID、行列定位与修复建议代码
- **历史记录**：执行留痕、状态过滤、一键复制 SQL

## 快速体验

```bash
git clone 本仓库
# 无需安装任何依赖，直接用浏览器打开 index.html
```

图表能力由 ECharts（CDN 引入）提供，其余全部为原生 HTML + CSS + JavaScript。
